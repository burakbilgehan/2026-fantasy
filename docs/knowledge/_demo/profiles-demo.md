# T-022 demo: 5 player profiles (2026-10-04, version 2)

Trial only. Written by hand in a session from the T-021 notes (96 videos) and our DB, not by a pipeline. Delete the `_demo` folder to undo.
Rules used: two channels (current, durable); facts stay, the newest verdict wins; no history; tags are separate items with a channel and an optional end condition; no limit on the number of tags, but a tag must be useful as a filter.
Stats are per game. FG% and FT% show attempts per game in brackets. Prices are in USD.
