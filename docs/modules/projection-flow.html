What runs when

Every hour (backend on)Each source checks its own age and refetches only when stale. The base is rebuilt once a day and the stored LLM decisions are applied again. Free.
When you add videosmake expert-digest then make knowledge-run. At its end the LLM layer reruns only for teams whose notes or roster changed.
Weekly or on newsmake projection-update: teams with changed notes or roster, a new prompt, or 7+ days old. About 1 USD per team.
Read the resultmake projection-review TEAM=all writes ALL.html. The site's value table reads the same rows (source "own").
