Decide each proposed tag below. One decision per proposal, in any order.

Actions:
- merge: the meaning is covered by an existing tag (same meaning, or a narrower case that the existing tag plus a detail text covers). `target` = the existing tag name, exactly as listed. Prefer merge.
- new: a meaning that no existing tag covers and that is worth filtering on for several players. `target` = the canonical name (short, generic, in the style of the list; can differ from the proposal). Give `meaning` (one sentence), `kind` (one of the kinds in the list, or a new kind only if none fits) and `channel` (durable or current). When several proposals share one new meaning, give them all the same `target`, `meaning`, `kind` and `channel`.
- drop: not useful as a filter (too vague, one player only by nature, a number that belongs in the stat table, a restatement of rank or price). Give `reason`.

Bad tags look like "two-category player", "first-round pick", "solid starter". Specific facts belong in a tag's detail, not in its name: "knee surgery" is the tag "injury prone" with that detail.
